# Security policy

Security reports are welcome for the current `main` branch.

Please use GitHub's private vulnerability reporting flow from the repository's
Security tab. Do not disclose exploit details, sensitive payloads, or affected
user data in a public issue. If private reporting is unavailable, open a public
issue containing only a request for a private contact channel.

Include the affected component, impact, reproduction conditions, and a minimal
proof of concept that contains no real credentials or personal data.

The documented trust boundaries, addressed threats, and residual risks are in
[`docs/threat-model.md`](docs/threat-model.md).
